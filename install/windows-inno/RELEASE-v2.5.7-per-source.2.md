# v2rayA v2.5.7-per-source.2 · Windows x64

修复前一版 `v2.5.7-per-source.1` 的核心版本不匹配。前一安装包把报告 `2.5.7` 的官方核心与报告 `v2.5.7-per-source.1` 的管理程序放在一起；v2rayA 要求二者的版本字符串完全一致，因此会显示 `CORE_VERSION_MISMATCH` 并拒绝启动核心。

本版从相同的 v2.5.7 源码构建管理程序和核心，两者均报告 `v2.5.7-per-source.2`。打包脚本现在会在编译安装包前检查两个版本，防止同类错误再次发布。请使用本版，勿安装 `.1`。

每订阅源独立控制更新的功能保持不变：可分别关闭自动更新、在服务启动时更新，或按各自的小时数定时更新。这样可对只有短时有效订阅链接的源关闭自动更新，而其他订阅继续按需更新。

Windows x64 安装包包含补丁版管理程序、匹配的 v2raya 核心、Wintun 与 geodata。已通过版本接口、核心配置及安装包解包核验。安装程序未签名，Windows 可能显示未知发布者。安装前请备份现有程序和数据。
